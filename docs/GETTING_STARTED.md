# 新手使用教程

这份教程只讲日常操作，不需要你会写代码。目标是先用**一款商品、一家门店**完成首次查询，再按需要增加任务。

如果你还没有打开页面，先请协助部署的人按照[部署指南](DEVELOPMENT.md)启动软件。GitHub 上的源码 ZIP 不是安装包，不能靠双击直接运行。

## 1. 先确认打开的是什么模式

- 顶部显示「本机实时库存查询」：可以查询真实门店取货库存。
- 顶部显示「离线预览」：仅用于体验界面，库存和操作是模拟的，不要用它判断是否可以买到。

本教程以本机实时库存查询模式为准。当前不需要登录 Apple 账号，也不要填写账号密码、身份证或付款信息。

## 2. 添加第一条监控

例如你想关注某款 iPhone 在上海一家门店的取货情况：

1. 点击左侧「商品管理」。
2. 在「购买地区」选择实际准备购买的地区，再选择 iPhone 品类。
3. 点击需要的产品系列。随后选择容量、颜色，再打开「选择具体配置」，勾选你真正想买的那一款。筛选只会缩小列表，**勾选配置才会选中商品**。
4. 在门店区域选择「城市 / 区域」，再打开「选择零售店」，勾选一家门店。
5. 查看底部的选择汇总。第一次建议显示「1 个 SKU × 1 家门店」，然后点击「添加 1 项」。
6. 点击左侧「监控任务」，确认列表里出现了正确的商品、容量、颜色和门店。

**SKU 是什么？** 可以把它理解为商品的具体配置。例如同一系列的 256GB 黑色与 512GB 黑色是两个 SKU，不是两个产品系列。你不需要记住那串 SKU 编号。

多选时，每个商品与每家门店都会组成一条任务：2 款配置 × 3 家门店，就是 6 条监控。实时浏览器模式最多 20 条，别一开始就把所有配置全选。

切换容量、颜色或城市筛选后，之前勾选的其他结果可能仍被保留。添加前请展开「已选…查看与移除」核对；界面会跳过已经存在的相同商品与门店组合。

## 3. 先点「查询一次」

在顶部点击「查询一次」，等待任务的「最后检查」出现新的时间，再查看库存状态。

| 看到的状态 | 含义与操作 |
|---|---|
| 待查询 | 还没有查到结果，先执行查询 |
| 有货 | 本次查询发现可取货；自行到官方购买页面确认商品、门店和价格 |
| 无货 | 本次查询该门店不可取货，不代表其他配置或门店也没有 |
| 未知、查询失败、被拦截或限流 | 没有可信库存结果，不等于无货；展开异常原因处理 |

**查询一次完成后自动暂停是正常的，不是软件坏了。** 单次查询只查一轮；需要下一次时再手动操作。系统有至少 60 秒的查询间隔保护，提示等待时不要反复点击。

## 4. 再开启持续监控

确认任务没有选错后，点击顶部「开始监控」。检查顶部是否变为运行状态，并观察后续「最后检查」时间是否更新。

- 最短查询间隔是 60 秒，可在「系统设置」中调整。
- 需要停止时点击「暂停监控」。暂停后保留的结果只是上次查询结果，不会继续更新。
- 电脑需要保持开机、联网且不休眠；启动服务的终端也要保持运行。
- 当前浏览器模式关闭全部实时页面约 10 秒后会自动暂停。重新打开页面后，请检查状态并手动启动，不要假设它一直在监控。
- 遇到 HTTP 541 或限流，服务会暂停，结果保持未知。它不会替你绕过平台限制。

当前页面的运行方式不同于原生桌面应用的托盘行为；请以页面顶部状态为准。

## 5. 日常管理任务

- **查找任务**：在「监控任务」搜索商品、SKU 或门店名称。
- **筛选结果**：选择有货、无货或未知状态。筛选只改变显示，不改变后台查询范围。
- **看完整信息**：点击商品名称或眼睛图标，查看完整规格、门店和最近结果。
- **编辑任务**：点击铅笔图标，修改目标后重新核对。
- **删除任务**：点击垃圾桶图标，确认后移除该任务。只想暂时停下来时，请用顶部「暂停监控」。
- **排查问题**：在「历史记录」查看当前会话的查询和活动日志。历史暂不跨重启保留。

## 6. 常见问题

### 「添加监控」为什么不能点？

通常是还没勾选具体配置或门店，或者选中的组合已经在列表中。先看底部是否同时显示已选商品与门店；目录尚在加载时，也要等它完成。

### 查询按钮为什么不能点？

先确认已经添加任务，页面已连接本机服务，且没有查询正在执行。初次加载或操作尚未结束时，按钮可能暂时不可用。若提示服务不可用，请让部署人员检查启动终端。

### 显示 HTTP 541，是不是没有货？

不是。它表示本次请求受到限制，没取得可信库存。展开「查看原因与处理建议」，保留完整错误，等待后再决定是否重查。不要连续点击，也不要用绕过验证码、风控的方式继续。

### 为什么看不到最新商品？

当前浏览器入口使用内置目录，不会自动刷新官网新品。没有某个配置不代表该商品不存在；请反馈具体地区和商品，不要选一个相似 SKU 代替。

### 可以在手机上收通知或自动买到吗？

当前浏览器版尚未接通手机推送，也不开放结账。不能因为「通知中心」「自动结账」有导航入口，就认为它们在此模式下已可用。

桌面版相关设置也只完成了本地模拟测试，不能把模拟成功当作真实手机送达或真实下单成功。现在建议将它作为库存查询辅助工具，购买由你在官方页面完成。

### 昨天的结果还在，能直接相信吗？

先看「最后检查」。库存会变化，暂停或断开后保留的旧结果不能当作当前库存，重新查询后再判断。

### 关闭后再开，需要重新添加任务吗？

在同一部署、同一数据目录中，任务设置会保存；重新启动后默认暂停，需要手动查询。换设备或换数据目录不会自动同步，当前会话历史也不会恢复。

### 页面打不开了怎么办？

本机服务不是永久在线的网站。请检查启动终端是否被关闭、电脑是否重启，以及是否使用了这次启动显示的地址。详细排查见[部署指南](DEVELOPMENT.md)。

## 遇到问题时提供什么

反馈所用模式、商品与门店、操作步骤、「最后检查」时间和完整错误文字。截图前遮住个人信息；不要发送 Bark Key、代理密钥、账号密码或浏览器资料目录。
